# Будущее труда в автоматизированной экономике

Учебная презентация (13 слайдов) о том, какие профессии сильнее и слабее
подвержены влиянию ИИ и автоматизации.

## Что в репозитории

| Файл | Назначение |
| --- | --- |
| `future-of-work.pptx` | Готовая презентация (PowerPoint) |
| `future-of-work.pdf` | Резервная копия для показа (на случай отказа техники) |
| `deck/` | Исходный код генератора презентации |
| `build.sh` | Сборка `.pptx` и `.pdf` одной командой |

## Как пересобрать

```bash
pip install python-pptx Pillow qrcode
./build.sh          # -> future-of-work.pptx + future-of-work.pdf
```

Для экспорта в PDF нужен LibreOffice (`soffice`). В этом контейнере он требует
`LD_LIBRARY_PATH=/usr/lib/libreoffice/program` — `build.sh` выставляет его сам.

## Дизайн-система

Соблюдены требования к оформлению:

- **Фон**: светлый `#F8F9FA` / тёмно-синий `#1A365D` на титульном и финальном.
- **Текст**: `#212529`; акценты — тёмно-синий `#1A365D`, зелёный `#2F855A`,
  оранжевый `#DD6B20` / красный `#C53030`. Не более трёх акцентов на слайд.
- **Шрифт**: один — Arial (рубленый), 18–40 pt.
- **Сетка**: единые поля ~1.8 см, правило третей, заполнение 60–70 %.
- **Графика**: векторные иконки (PIL, без растровых артефактов), диаграммы,
  таблица, QR-код. Все пары текст/фон проходят WCAG AA по контрасту.
- **Анимация**: только сдержанное появление (fade / wipe / zoom) там, где
  ТЗ её разрешает; титульный и финальный слайды — без анимации.

## Источники данных

- Frey C. B., Osborne M. A. *The Future of Employment*. Oxford, 2017 — доля
  автоматизируемых задач по профессиям (кассиры 97 %, бухгалтерия 98 %).
- McKinsey Global Institute. *Generative AI and the Future of Work*, 2023 —
  до 30 % рабочих часов в США автоматизируемы к 2030 году.
- IMF. *Gen-AI: Artificial Intelligence and the Future of Work*, 2024 —
  около 40 % рабочих мест в мире затронет ИИ.
- World Economic Forum. *Future of Jobs Report*, 2025 — рост социальных и
  падение рутинных профессий к 2030 году.
- PwC. *Global Workforce Hopes and Fears Survey*, 2023.
