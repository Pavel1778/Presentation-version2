# Будущее труда в автоматизированной экономике

Учебная презентация (14 слайдов) о том, какие профессии сильнее и слабее
подвержены влиянию ИИ и автоматизации.

Автор: **Кобзев Тимой**, группа **ИС-24**.

## Что в репозитории

| Файл | Назначение |
| --- | --- |
| `future-of-work.pptx` | Готовая презентация (PowerPoint) |
| `future-of-work.pdf` | Резервная копия для показа (на случай отказа техники) |
| `deck/` | Исходный код генератора презентации |
| `build.sh` | Сборка `.pptx` и `.pdf` одной командой |

## Как пересобрать

```bash
pip install python-pptx Pillow qrcode
./build.sh          # -> future-of-work.pptx + future-of-work.pdf
```

Для экспорта в PDF нужен LibreOffice (`soffice`). В этом контейнере он требует
`LD_LIBRARY_PATH=/usr/lib/libreoffice/program` — `build.sh` выставляет его сам.

## Дизайн-система

- **Два цвета** + нейтрали: тёмно-синий `#1A365D` (структура, устойчивость)
  и оранжевый `#DD6B20` (риск, внимание). Фон — светлый `#F8F9FA`, на
  титуле и финале — глубокий синий `#122A4A`. Цвет несёт смысл, а не декор.
- **Шрифт**: один — Arial, 18–46 pt (минимальный размер 18 pt).
- **Фоны**: не однотонная заливка, а узоры — точечные сетки, полутоновые
  «растры», дуги в углах и диагональные ленты.
- **Наглядность**: векторные иконки, столбчатая и линейная диаграммы,
  таблица, изотип-«вафля» (1 из 100), QR-код. Все пары текст/фон проходят
  WCAG AA по контрасту.
- **Анимация**: только сдержанное появление (fade / wipe / zoom) там, где
  уместно; титульный и финальный слайды — без анимации.
